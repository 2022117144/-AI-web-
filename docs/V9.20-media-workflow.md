# V9.20：配音、字幕与成片导出修复

V9.19 合成和发送阶段存在占位实现，页面能在缺少有效成片时显示完成；分镜配音未接入，部分生成错误被吞掉。V9.20 将执行统一到后端，页面只提交任务、读取状态和取消指定任务。

## 使用

1. 保存项目文案并分析分镜，确认每个分镜有旁白文本。
2. 分镜表的「配音」生成当前行旁白，在原有列内提供播放控件。
3. 流水线可选择背景音乐，也可仅保留旁白。
4. 点击「执行流水线」。任务在后端继续，切换页面或刷新后仍可查看进度。
5. 最后两个阶段执行真实合成及验证，成功后提供成片链接。步骤 6 名称为「成片导出」。

已有有效素材复用。手动修改画面提示词后，使用原有重新生成按钮更新图片和视频。修改总文案后，应重新分析并核对分镜；程序不自动判断原分镜是否适用。

## 媒体处理

- Edge TTS 生成逐镜头 MP3 和实际 WordBoundary 时间戳；ffprobe 测量时长，替代字节数估算。
- 统一分辨率、24 fps、SAR、H.264/yuv420p 和 AAC 音轨。
- 视频短于旁白时保持最后一帧，字幕按各段实际时长累积偏移。
- libass 烧录中文字幕，字体 Microsoft YaHei，字号使用 ASS 虚拟画布单位。
- 配乐循环补齐，旁白触发自动压低音乐，末尾淡出并限制峰值。
- 验证成片视频、音频及时间长度。输入指纹或文件大小、修改时间改变后，原导出不再视为完成。
- 本地配音、编码及轮询支持取消；已提交第三方的任务是否继续计费取决于供应商取消能力。

## 文件和接口

项目目录：zc_backend/data/project_content/项目ID/。

| 文件 | 内容 |
| --- | --- |
| 音频/narration.json | 分镜文本、音色、MP3、真实时长和字幕时间戳 |
| 视频提示词/srt.json | 实际字幕时间线，时间使用秒数 |
| 视频/captions.srt | 成片字幕 |
| 视频/merged_video.mp4 | 成片 |
| 视频/export.json | 输出地址、时长及源文件指纹 |

POST /api/pipeline/run 的 config.action 支持 full、voice、export。voice 可传零起始 shot_index。ffmpeg_merge 可传 ratio、项目内 bgm_path、music_volume（0–1）。

POST /api/projects/项目ID/background-music 接收原始音频，限制 30 MB，校验后转为 MP3。取消使用运行 ID；同一项目同时只允许一个媒体任务。重启后执行中的历史记录显示中断错误，保留配置供重试。

## 依赖与验证

使用项目 .venv/Scripts/python.exe，安装 requirements.txt。PATH 包含 FFmpeg/ffprobe，FFmpeg 需要 libx264、libass；中文字体使用 Microsoft YaHei。配音需要联网，代理可通过 EDGE_TTS_PROXY 设置。

回归命令：python -m unittest discover -s tests -v。覆盖实际 FFmpeg 拼接、长旁白、混合尺寸帧率、短配乐、缺失和过期素材、失败及取消、重启、冲突、配音接口和配乐上传。

测试使用独立临时项目。免费中文 TTS 和 FFmpeg 另做真实短片验证；付费图片、视频供应商未进行完整实扣费测试。浏览器工具因保存的访问权限无法验证而受阻，未完成页面视觉操作验收。
